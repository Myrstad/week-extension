# Week Extension

Week extension is an extension focused on showing the current week number. Check the current week number at a glance in the extension icon. With numerous settings for theme, icon color, and "click to copy" features.

### Project info

The extension is based on [WXT](https://wxt.dev/) and [Svelte](https://svelte.dev/) for the main technologies. With [iro.js](https://iro.js.org/) for color picker and [material color utilizes](https://github.com/material-foundation/material-color-utilities) for generating a material 3 color palette.

The entrypoint for the popup is located at `src/entrypoint/popup/index.html` and the background script entrypoint at `src/entrypoint/background.ts`
